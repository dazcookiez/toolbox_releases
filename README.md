# Vega Toolbox : téléchargements

Les exécutables de **Vega Toolbox** sont publiés ici. Le code source est dans un dépôt privé.

➡️ **[Dernière version](https://github.com/dazcookiez/toolbox_releases/releases/latest)**

| Fichier | Poste |
|:--|:--|
| `vega_toolbox.exe` | Windows 8.1+ / Server 2012 R2+ |
| `vega_toolbox_legacy_x64.exe` | Windows 7 SP1 / Server 2008 R2 → Server 2012 (64 bits) |
| `vega_toolbox_legacy_x86.exe` | Windows 7 SP1 / Server 2008 R2 → Server 2012 (32 bits) |

À partir de la 5.0.2, l'application se met à jour d'elle-même depuis ce dépôt (vérification SHA-256 via `latest.json`).
Les versions 3.7.8 à 5.0.0 ont été importées depuis l'ancien GitLab de Bastien Tillier.
